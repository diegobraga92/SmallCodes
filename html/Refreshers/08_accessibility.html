1. What is Web Accessibility?

Principle Description Example
Perceivable Users must be able to perceive the content Alt text on images, captions on videos
Operable Users must be able to operate the interface Keyboard navigation, sufficient time limits
Understandable Content and UI must be understandable Clear language, predictable navigation
Robust Content must work with assistive technologies Valid HTML, proper ARIA usage
WCAG Levels:
  • Level A: Minimum level (essential for some users)
  • Level AA: Recommended (addresses most barriers) — target this
  • Level AAA: Highest level (not possible for all content)

Focus Management

// Move focus to an element
function openDialog(dialogId) {
    const dialog = document.getElementById(dialogId);
    dialog.style.display = 'block';
    dialog.focus();  // Move focus to dialog
}

// Trap focus within a modal
function trapFocus(element) {
    const focusable = element.querySelectorAll(
        'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
    );
    const first = focusable[0];
    const last = focusable[focusable.length - 1];

    element.addEventListener('keydown', (e) => {
        if (e.key === 'Tab') {
            if (e.shiftKey && document.activeElement === first) {
                e.preventDefault();
                last.focus();
            } else if (!e.shiftKey && document.activeElement === last) {
                e.preventDefault();
                first.focus();
            }
        }

        if (e.key === 'Escape') {
            closeDialog();
        }
    });
}

// Restore focus when closing
let previousFocus;

function openModal() {
    previousFocus = document.activeElement;
    document.getElementById('modal').style.display = 'block';
}

function closeModal() {
    document.getElementById('modal').style.display = 'none';
    previousFocus.focus();  // Return focus to trigger element
}

Visible Focus Indicators

/* Never do this! */
*:focus { outline: none; }

/* Instead, provide visible focus styles */
:focus-visible {
    outline: 2px solid #e44d26;
    outline-offset: 2px;
}

/* Custom focus style for specific elements */
button:focus-visible {
    box-shadow: 0 0 0 3px rgba(228, 77, 38, 0.4);
}

/* High contrast mode support */
@media (forced-colors: active) {
    :focus-visible {
        outline: 2px solid Highlight;
    }
}

Manual Testing Checklist

Test How to Test What to Check
Keyboard navigation Tab through the page All interactive elements are reachable and operable
Screen reader Use VoiceOver, NVDA, or JAWS Content is announced correctly, landmarks are present
Zoom Zoom to 200% in browser Content doesn't overlap or get cut off
Color contrast Use contrast checker 4.5:1 for normal text, 3:1 for large text
Forms Submit with errors Errors are announced and focus moves to error
Reduced motion Enable prefers-reduced-motion Animations are disabled or reduced
