3. Open Graph Protocol (Facebook, LinkedIn)
OG image best practices:
  • Size: 1200×630px (1.91:1 aspect ratio)
  • Keep text within the safe zone (center 600×600px)
  • Use high contrast for readability
  • Include your logo and page title
  • Test with the Facebook Sharing Debugger

4. Twitter Cards
OG + Twitter: Twitter falls back to OG tags if Twitter tags are missing. For consistency, duplicate the key values (title, description, image) in both formats.

5. Canonical URLs and Hreflang

Canonical URLs

Hreflang (Language/Region Alternatives)
Hreflang rules:
  • Each language variant must link back to all others (bidirectional)
  • Include a self-referencing hreflang tag
  • Use ISO 639-1 language codes (en, es, fr)
  • Use ISO 3166-1 alpha-2 region codes (US, GB, DE)
