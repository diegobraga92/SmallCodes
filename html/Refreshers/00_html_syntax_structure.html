Attribute Types

Attribute Example Description
id id="header" Unique identifier (must be unique per page)
class class="container active" CSS class(es), can be reused, space-separated list
style style="color: red;" Inline CSS (avoid when possible, use classes)
data-* data-user-id="42" Custom data attributes for JavaScript
hidden hidden Boolean attribute, hides the element
title title="Tooltip text" Tooltip on hover (use sparingly for accessibility)
tabindex tabindex="0" Controls keyboard tab order
aria-* aria-label="Close" Accessibility attributes (see file 08)
Boolean Attributes: Some attributes are boolean — their presence means true, absence means false. Examples: hidden, disabled, checked, required, readonly. Write them as or .
