1. Image Element Basics
Alt text is required! Every must have an alt attribute. If the image is purely decorative, use alt="" (empty alt) so screen readers skip it. Never omit the alt attribute entirely.

Alt Text Guidelines

Image Type Alt Text Example
Informative Describe the content alt="Red apple on a wooden table"
Decorative Empty alt alt=""
Functional (link/button) Describe the action alt="View product details"
Logo Company name alt="Acme Corp"
Icon Describe the icon's meaning alt="Search"
Complex (chart/graph) Brief summary + link to data alt="Bar chart showing Q1 sales"

2. Responsive Images

srcset and sizes Attributes
How srcset works: The browser knows its viewport width and device pixel ratio. It uses the sizes attribute to calculate how many CSS pixels the image will occupy, then picks the best source from srcset. You don't need JavaScript — it's built into HTML.

6. Image Formats and Performance

Format Compression Transparency Animation Best For
JPEG/JPG Lossy No No Photos, complex images
PNG Lossless Yes No Screenshots, logos, graphics with text
GIF Lossless Yes (1-bit) Yes Simple animations, memes
WebP Both Yes Yes Modern replacement for JPEG/PNG/GIF (smaller files)
AVIF Both Yes Yes Next-gen format, best compression (limited browser support)
SVG Vector Yes Yes Icons, logos, illustrations (scales infinitely)

Performance Best Practices
Image optimization checklist:
  • Resize images to the maximum display size needed
  • Use WebP/AVIF with JPEG/PNG fallback
  • Compress with tools like Squoosh, ImageOptim, or Sharp
  • Set explicit width and height attributes
  • Use loading="lazy" for non-critical images
  • Use fetchpriority="high" for hero/LCP images
  • Serve responsive images with srcset

Media Accessibility Checklist

  • Alt text: Every image needs alt text (descriptive or empty for decorative)
  • Captions: Videos need captions for deaf/hard-of-hearing users
  • Transcripts: Audio content needs text transcripts
  • Audio descriptions: Videos need narration of visual information
  • Controls: Media players need accessible controls (keyboard operable)
  • Contrast: Text overlays on images need sufficient contrast
  • ARIA: Use role="img" and aria-label for SVG icons

8. Media Source Fallbacks
Fallback order: List sources from most modern/desirable to least. The browser picks the first format it supports. Always include a text fallback inside the element for browsers that don't support the element at all.
