HTML Performance Optimization

1. Critical Rendering Path
CRP optimization goals:
  • First Paint (FP): ≤ 1.0s
  • First Contentful Paint (FCP): ≤ 1.8s
  • Largest Contentful Paint (LCP): ≤ 2.5s
  • Time to Interactive (TTI): ≤ 3.8s

2. Resource Loading Strategies

Strategy Syntax Use Case
Blocking
Async vs Defer:
  • Async: Download in parallel, execute immediately when ready. Order not guaranteed. Use for independent scripts.
  • Defer: Download in parallel, execute after HTML parsing in document order. Use for scripts that depend on DOM or other scripts.
  • Module: Deferred by default. Use for modern ES module scripts.

/*
    Performance Budget:
    - Total page weight: < 500KB
    - Time to Interactive: < 3.8s
    - LCP: < 2.5s
    - CLS: < 0.1

Performance checklist:
  • Measure baseline performance with Lighthouse
  • Optimize images (modern formats, responsive, lazy loading)
  • Defer non-critical CSS and JavaScript
  • Preload critical resources (fonts, hero images)
  • Set explicit dimensions on all media elements
  • Use font-display: swap for web fonts
  • Minimize render-blocking resources
  • Use a CDN for static assets
  • Enable compression (Brotli, Gzip)
  • Set up performance monitoring
