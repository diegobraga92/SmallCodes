7. Link States and Styling

/* Link states - LVHA order */
a:link { color: blue; }           /* Unvisited link */
a:visited { color: purple; }      /* Visited link */
a:hover { color: red; }           /* Mouse hover */
a:active { color: orange; }       /* While being clicked */

/* Focus state (keyboard navigation) */
a:focus {
    outline: 2px solid blue;
    outline-offset: 2px;
}

/* Remove underline on nav links, keep for content */
nav a { text-decoration: none; }
nav a:hover { text-decoration: underline; }

/* Style external links with an icon */
a[href^="http"]::after {
    content: " ↗";
    font-size: 0.8em;
}
Don't remove focus outlines! The :focus outline is essential for keyboard users. If you remove the default outline, replace it with a custom focus style that has sufficient contrast.

8. SEO and rel Attributes

rel Value Purpose Example
noopener Prevents new page from accessing window.opener target="_blank" rel="noopener"
noreferrer Hides referrer information from the target rel="noreferrer"
nofollow Tells search engines not to follow the link rel="nofollow" (user-generated content)
noindex Tells search engines not to index the target rel="noindex"
external Indicates link is to an external site rel="external"
prev / next Pagination (previous/next page) rel="prev" / rel="next"
canonical Specifies the preferred URL (in )
alternate Alternate version (different language, format) rel="alternate" hreflang="es"
author Link to author page rel="author"
help Link to help/documentation rel="help"
license Link to license information rel="license"
tag Link to a tag/category page rel="tag"
