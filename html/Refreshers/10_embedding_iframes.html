3. Cross-Origin Communication (postMessage)
Always verify origin! Never use postMessage without checking event.origin. An attacker could send malicious messages from a different origin. Always specify the target origin in postMessage — never use *.

Technique 1: Aspect Ratio Container (CSS)




    




.iframe-container {
    position: relative;
    overflow: hidden;
    width: 100%;
    padding-top: 56.25%;  /* 16:9 aspect ratio (9/16 = 0.5625) */
}

.iframe-container iframe {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    border: 0;
}

/* Different aspect ratios */
/* 16:9 → padding-top: 56.25% */
/* 4:3  → padding-top: 75% */
/* 1:1  → padding-top: 100% */
/* 21:9 → padding-top: 42.86% */

8. Accessibility for Embedded Content
Embedding checklist:
  • Always include a descriptive title attribute
  • Use sandbox to restrict untrusted content
  • Use loading="lazy" for non-critical embeds
  • Make iframes responsive with aspect-ratio containers
  • Verify origins when using postMessage
  • Provide fallback content for accessibility
  • Consider privacy implications of third-party embeds
  • Test keyboard navigation through embedded content
