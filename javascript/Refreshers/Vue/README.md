# Vue Refreshers

Comprehensive Vue.js guide from basics to upper-mid level.

### Fundamentals 📝
- **00_vue_basics.vue** 📝 - Template syntax, directives, data binding
- **01_composition_api.vue** 📝 - setup(), ref, reactive, computed
- **02_components.vue** 📝 - Single File Components, registration
- **03_props_emits.vue** 📝 - Props, custom events, v-model

### Intermediate 📝
- **04_lifecycle.vue** 📝 - Lifecycle hooks, onMounted, onUnmounted
- **05_computed_watchers.vue** 📝 - Computed properties, watchers

- **07_routing.vue** 📝 - Vue Router, navigation, route params
- **08_state_management.vue** 📝 - Pinia/Vuex, global state
- **09_forms.vue** 📝 - Form handling, validation

## 💡 Quick Tips

- Composition API is the modern standard
- Single File Components (.vue)
- Reactive data with ref() and reactive()
- v-model for two-way binding
- Pinia for state management
- Vue Router for SPAs
