# Angular Refreshers

Comprehensive Angular guide from basics to upper-mid level.

## 📚 Topics Covered

### Fundamentals 📝
- **00_components.ts** 📝 - Components, decorators, templates
- **01_templates.ts** 📝 - Template syntax, interpolation, directives
- **02_directives.ts** 📝 - *ngIf, *ngFor, custom directives
- **03_services.ts** 📝 - Services, business logic separation

### Intermediate 📝
- **04_dependency_injection.ts** 📝 - DI system, providers
- **05_routing.ts** 📝 - Router, navigation, guards
- **06_forms.ts** 📝 - Template-driven, reactive forms
- **07_http.ts** 📝 - HttpClient, interceptors
- **08_observables.ts** 📝 - RxJS, operators, async pipe
- **09_modules.ts** 📝 - NgModules, lazy loading
- **10_typescript.ts** 📝 - TypeScript patterns in Angular

- TypeScript is required
- Decorators for metadata
- Dependency injection built-in
- RxJS for async operations
- Reactive forms preferred
- CLI for project management
