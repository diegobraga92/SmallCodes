# JavaScript Refreshers

Comprehensive JavaScript guide from junior to senior level, covering pure JavaScript and major frameworks.

## 📚 Pure JavaScript Core

### Junior Level (Fundamentals)
- **00_basics.js** - Variables, data types, operators, type conversion
- **01_control_flow.js** - if/else, switch, loops, try/catch
- **02_functions.js** - Declarations, expressions, arrow functions, closures

### Mid Level (Core Skills)
- **03_arrays.js** - Array methods, iteration, destructuring, spread/rest
- **04_objects.js** - Object creation, methods, prototypes, destructuring
- **05_classes.js** - ES6 classes, inheritance, static methods, getters/setters
- **06_async_basics.js** - Callbacks, promises, async/await, error handling
- **07_es6_features.js** - Let/const, destructuring, modules, template literals
- **08_dom_manipulation.js** - Selecting elements, modifying DOM, events
- **09_events.js** - Event handling, delegation, custom events
- **10_modules.js** - ES6 modules, import/export, dynamic imports

### Senior Level (Advanced)
- **11_advanced_async.js** - Promise.all/race, async patterns, concurrency
- **12_error_handling.js** - Custom errors, error boundaries, logging
- **13_design_patterns.js** - Module, Observer, Factory, Singleton patterns
- **14_prototypes_inheritance.js** - Prototype chain, Object.create, composition
- **15_functional_programming.js** - Pure functions, immutability, composition
- **16_performance.js** - Optimization, debounce, throttle, memoization
- **17_memory_management.js** - Garbage collection, memory leaks, WeakMap/WeakSet
- **18_regex.js** - Regular expressions, patterns, common use cases
- **19_fetch_api.js** - HTTP requests, REST APIs, headers, error handling
- **20_testing.js** - Jest, unit tests, mocks, integration tests
- **21_security.js** - XSS, CSRF, sanitization, best practices
- **22_web_apis.js** - localStorage, sessionStorage, IndexedDB, Web Workers
- **23_advanced_features.js** - Proxies, Reflect, Symbols, Generators

## 📖 How to Use

1. **Start with Basics** - Begin with 00-02 for fundamentals
2. **Progress Through Levels** - Move through numbered files sequentially
3. **Practice as You Go** - Run each file and experiment with the code
4. **Framework Specialization** - Once core JS is solid, dive into frameworks

## 🎯 Learning Path

### Path 1: Frontend Developer
`Basics → Core JS → DOM/Events → Framework (React/Vue/Angular)`

### Path 2: Backend Developer
`Basics → Core JS → Async → Node.js → Express → Database`

### Path 3: Full-Stack Developer
`Basics → Core JS → Node/Express → React/Next → TypeScript`

## 💡 Best Practices

- Always use strict mode (`'use strict'`)
- Prefer `const` over `let`, never use `var`
- Use ES6+ features (arrow functions, destructuring, etc.)
- Write pure functions when possible
- Handle errors gracefully
- Keep code DRY (Don't Repeat Yourself)
- Use meaningful variable and function names
- Comment complex logic
- Test your code
